# Step 7 metrics and examples

The metrics module evaluates saved assignments without fitting a model. It preserves input document order and validates unique nonnegative integer IDs, integer cluster labels (`-1` is noise), finite feature arrays, and square symmetric nonnegative precomputed dissimilarities with zero diagonal. Numerical roundoff within the declared matrix tolerances is symmetrized and the diagonal reset to zero.

Two scopes are saved: including noise treats `-1` as one group; excluding noise removes those documents. Each scope reports its document count and coverage relative to the entire input. Supervised metrics and purity use only available string reference labels; `None` and NaN are missing. `labeled_document_count` and `labeled_coverage` expose that denominator separately. Internal metrics always use every document in the scope. Fewer than two labeled documents produces unavailable agreement scores with a reason. Purity needs one labeled document.

ARI, NMI, AMI, homogeneity, completeness and V-measure follow [scikit-learn's clustering evaluation definitions](https://scikit-learn.org/stable/modules/clustering.html#clustering-performance-evaluation); NMI/AMI arithmetic averaging and V-measure beta=1 are explicit in policy. Weighted purity is the sum of each group's largest reference-label count divided by the number of labeled documents.

Silhouette uses full Euclidean pairwise distances from supplied fixed features or the supplied validated nonmetric dissimilarity. It needs between two and `n_documents - 1` groups; singleton-group samples contribute zero, following the [silhouette API](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.silhouette_score.html). [Davies–Bouldin](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.davies_bouldin_score.html) and [Calinski–Harabasz](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.calinski_harabasz_score.html) use only original Euclidean feature vectors and never distance-matrix rows. Unsupported or undefined results store null plus a reason. Coincident cluster centroids make Davies–Bouldin unavailable because its separation denominator is zero; zero within-cluster sum of squares makes Calinski–Harabasz unavailable. Distinct zero-scatter clusters retain their valid Davies–Bouldin value of zero. No further feature normalization is applied here.

For each non-noise cluster, the representative is its minimum sum-distance medoid. Additional representatives are its nearest members. Candidate outliers are the farthest members from the same medoid. Exact ties use ascending document ID. These computations do not use reference labels, and representative and outlier lists can overlap in small clusters. Noise has neither representatives nor outliers. All equally frequent dominant labels are accepted for the majority-mismatch flag; missing labels and noise never receive that flag. A mismatch or outlier is only a review candidate.

Mixing both pairs has ARI `-0.5`. These expectations come from literal distances and partition pair counts.
